# Tambu Game — Game Design

## Premisa

Juego 2D pixel-art de comedia social. Tambu intenta atravesar una noche de fiesta, hablar con distintas mujeres y sobrevivir a la interferencia de su grupo de amigos.

## Loop inicial

1. Llegada de Tambu.
2. Exploración libre del mapa.
3. Detectar NPC interactuables.
4. Conversaciones por rondas.
5. Consultar a miembros del grupo cuando corresponda.
6. Resolver la interacción con distintos resultados.
7. Acumular puntos / perder vidas / modificar estados.

## Sistemas previstos

- Vidas.
- Puntos.
- Alcohol.
- Atracción.
- Confianza.
- Intensidad.
- El Consejo.
- Conversaciones ramificadas.
- Eventos aleatorios.
- Distintos desenlaces por NPC.

## Primer mapa

### Fiesta en el patio

Debe incluir:

- casa de fondo;
- patio amplio;
- césped;
- piscina;
- barra;
- DJ;
- luces;
- baño visible;
- basura ligera de fiesta;
- NPCs de relleno;
- 2–3 mujeres interactuables;
- grupo de amigos distribuido por el mapa.

## Principio de desarrollo

Primero diversión y lectura visual. Los assets importantes se refinan después. Los NPCs secundarios y props deben ser reutilizables y baratos de producir.
